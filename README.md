## 🚗 Gerenciador de Garagem

Um sistema simples em Python para gerenciar veículos, permitindo **cadastrar, listar, editar e deletar carros**, com armazenamento em arquivo JSON.

---

## 📌 Funcionalidades

✔ Cadastrar veículos  
✔ Listar veículos em formato de lista  
✔ Listar veículos em formato de tabela 📊  
✔ Editar informações de um veículo  
✔ Deletar veículos  
✔ Persistência de dados em arquivo JSON 💾  

---

## 🧠 Tecnologias utilizadas

- Python 🐍  
- JSON 📄  
- Biblioteca Tabulate 📊  

---

## 📦 Instalação

1. Clone o repositório:

```bash
git clone https://github.com/JhonatanResende/Gerenciador-de-Garagem

```

---

## 📂 Acesse a pasta do projeto

```bash
cd Gerenciador-de-Garagem
```

---

## 🧪 Crie e ative o ambiente virtual

### 🪟 Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

---

## 📦 Instale as dependências

```bash
pip install -r requirements.txt
```

---

## ▶️ Execute o projeto

```bash
python Gerenciador-de-Garagem.py
```

---

## 📂 Estrutura do projeto

Gerenciador-de-Garagem/

│

├── Gerenciador-de-Garagem.py

├── requirements.txt

├── .gitignore

└── carros.json (criado automaticamente)

---

## 💾 Persistência de dados

Os veículos cadastrados são salvos automaticamente no arquivo:

carros.json

Isso permite que os dados continuem salvos mesmo após fechar o programa.

---

## 📊 Menu do sistema
1. Cadastrar veículo
2. Exibir veículos cadastrados (lista)
3. Exibir veículos cadastrados (tabela)
4. Editar veículo
5. Deletar veículo
6. Sair
